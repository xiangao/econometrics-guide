References

This guide draws on a handful of textbooks, the original papers behind the estimators discussed, and package documentation. The list below collects every work the guide rests on. The bibliography source is references.bib in the book repository. Keys shared with the two causal econometrics guides and the blog book are kept unchanged, so a passage can move between the books without a key being renamed.

Besides the works cited in the chapters, the guide draws throughout on the textbooks of Baltagi (2013), Baum (2006) and Greene (1993). Greene is cited from the 1993 edition; chapter, example and table numbers differ across editions.

The R packages loaded in the code examples are cobalt, DRDID, fixest, ggfortify, gmm, ivreg, knitr, MASS, OutcomeWeights, plm, sandwich, strucchange, survival, synthdid, and WeightIt, run under R (R Core Team). Stata examples use Stata (StataCorp).
